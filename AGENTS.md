# Archive project instructions

Before researching, editing or packaging any archive, read [ARCHIVE_STANDARD.md](ARCHIVE_STANDARD.md) in full. It records Wakka’s settled research, writing, preservation and UI requirements across all six archives. Apply it without reopening settled decisions. Later explicit user instructions take precedence.

Continue from the repository’s research/STATUS.md and research log when present. Record searches and unresolved leads as work proceeds. Do not invent previous search history or infer completeness from citations, word counts or successful UI checks.

Include AGENTS.md, ARCHIVE_STANDARD.md and the current research continuity files in future upload-ready packages. Merge these archive instructions into any existing AGENTS.md without discarding its requirements. Carry the same standard into each remaining repository before implementation; preserve that repository’s own colour scheme. Do not push or upload to GitHub unless Wakka requests it.
