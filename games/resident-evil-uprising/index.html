Resident Evil: Uprising

Claire Redfield and Leon Kennedy return to Raccoon City in an isometric version of Resident Evil 2.

About the game

In the Java game you can change between Claire and Leon in the menu. They cross Raccoon City on a grid, which affects how you fight. A zombie following the same grid can be lined up in your path before you shoot, and narrow corridors constrain where either character can go.[1]

Development

Capcom presented Uprising as a new take on Resident Evil 2 for phones. The isometric layout changes how you move and aim. Contemporary screenshots published by Mobile Gamer Brasil trace back to Capcom Mobile’s promotional slideshow and show the phone game before release.[2][1][3]

Release and reception

Pocket Gamer covered Capcom’s announcement in May 2009 and reviewed the Java game in November. Later that month Capcom and Gameloft announced a distribution deal covering Europe, the Middle East and Africa, with Uprising among the games slated for that distribution window.[2][1][4][5]
