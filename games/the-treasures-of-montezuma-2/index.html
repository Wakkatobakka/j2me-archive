The Treasures of Montezuma 2

Match coloured tiles before the timer runs out and spend the gold you earn on upgrades.

About the game

The mobile game sets tasks for each timed board. Making sequences of the same colour earns points and gold. The gold pays for bonuses that can help you finish later boards as you work toward rebuilding Tenochtitlan.[1]

Development

The Java credits put the phone adaptation with HeroCraft and Mobile-Games Ltd., and distinguish it from Alawar’s PC production. Oleg Tsyganov managed the project and programmed it with Victor Yarmola. Katya Kuznetsova and Olga Ulrich made the art.[2]

Release and reception

MobyGames dates HeroCraft’s Java release to October 2010. In October 2011, Ukrainian carrier life:) announced a free HeroCraft edition on its portal for touchscreen phones. The carrier did not specify the runtime for its download.[3][1]
