Ancient Empires II

Galamar and Valadorn fight side by side against an enemy that knows how to gang up on a weakened unit.

About the game

The brothers from the first game team up to keep Saeth from taking control of Thorin. Across eight missions, a catapult can knock down a building and infantry can repair it and claim the site. Enemy units can work together, so leaving a wounded soldier exposed can cost a turn’s worth of progress.[1]

Alongside the campaign, the Java game has a skirmish mode where up to four people can take turns in the same fight.[2]

Release and reception

The UK Java release is listed in June 2005, with Macrospace as developer and Glu Mobile as publisher. In February 2006, the Academy of Interactive Arts & Sciences named it Cellular Game of the Year.[3][4]
