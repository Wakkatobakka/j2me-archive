Fantasy Worlds: Rhynn

A free Java MMO with character classes, quests and a chat window for meeting other players.

About the game

Choose one of four character types, then gain levels through quests and combat. Rhynn was free to play, with any data charges falling to the player. In 2010 the site BoostApps tested it on a Motorola i776 and found that reconnecting could require restarting the game.[1][2]

Development

Norbert Nopper is credited with the original concept. Jochai Papke led the project and programming, while Jan-Eric Lauble worked across game design, graphics and levels. Papke’s repository includes the client, server and worldbuilder. The README identifies the code as based on versions 1.4 and later.[1][3]

Release and reception

MobyGames dates the Java release to October 2008 and identifies AwareDreams as the developer and macrolutions Ltd. as publisher. A server update in 2010 made client version 1.3.7 mandatory. By March 2012, BoostApps had reported that the original servers were down.[1][2]

Papke identifies Rhynn-X as the revival he is involved in. OpenRhynn also uses the game’s released source and describes itself as a fan remake.[3][4]
