Critter Crunch

Feed a small critter to a bigger one, then use the bigger one to set off a chain reaction.

About the game

Biggs snatches critters with his tongue and feeds them back into the rows creeping down the screen. Overfill one and its neighbours of the same colour can burst too. Adventure mode keeps the rows coming, while Puzzle mode gives you a fixed number of moves to clear the board.[1][2]

Development

Capybara spent about a month making a prototype before getting the go-ahead. The programmers could switch individual rules on and off to test different combinations, and the designers used an in-house editor to build levels. The team also made a tool to help port its J2ME games to BREW.[2]

Vic Nguyen drew and animated the critters, and David Hoang worked on the jungle backgrounds. Kenneth Yeung built a library of procedural effects. The Java credits also list Living Mobile Czech, whose team worked on the port.[2][3][4]

Lead programmer Radek Koncewicz recalls one rule players struggled to follow. Neighbouring critters originally joined a chain only if they had eaten the same amount. He suggested matching by colour alone, which let players see the next link before they fed the first critter. He also added sliders to the editor so designers could tune how often blockers and powerups appeared in different levels.[5]

Release and reception

Pocket Gamer reviewed Disney’s Java release in August 2007. Java release records list Starwave Mobile in the US and Living Mobile in the UK. Capybara’s mobile game won Best Game and Achievement in Art at the 2008 IGF Mobile awards.[1][6][4]
