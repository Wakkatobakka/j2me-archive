Company of Heroes

The Java adaptation puts Able Company’s Normandy campaign on a turn-based grid.

About the game

Pick the units for a mission and deploy them before the first turn. A cursor and colour-coded grid show where each unit can move or fire. Buildings and shell craters provide cover, and some objectives call for holding ground through a counterattack.[1][2]

Development

Viva La Mobile developed the Java release for THQ Wireless. The mobile credits put John Murphy in both production and development, with David Kainer in production, Tony Schofield and Ian Hosken in development, and James Croke and Jeremy Kupsch in art.[3][4]

Artist Bill Harbison supplied Java mock-ups to Games That Weren’t in 2024. His name appears in the Java credits for Worms 2007. The surviving evidence leaves open how his Company of Heroes artwork relates to the Viva La Mobile release.[5][4][6]

Release and reception

Pocket Gamer announced a turn-based phone game in August 2006 and reviewed the Java release that November. Games That Weren’t later discussed the mock-ups as potentially unreleased work. The contemporary review and Java credits document a released adaptation.[1][2][3][5]
