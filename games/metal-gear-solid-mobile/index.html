Metal Gear Solid Mobile

SoftBank's 2009 Java release brought the original 3D stealth game to the Sharp 932SH.

About the game

Solid Snake and Otacon investigate a facility making Metal Gear after the Shadow Moses incident. Konami's Japanese release shows Snake using the walls and his surroundings to get past guards. The Sharp 932SH was the SoftBank handset named for the release.[1][2]

Development

SoftBank expanded S! Appli so Java games could access OpenGL ES 1.1. Keitai Watch reported that the new format raised the JAR limit from 1 MB to 3 MB and allowed as much as 16 MB of heap. A trial of Metal Gear Solid Mobile was preinstalled on the Sharp 932SH.[3][4]

Nokia credited Ideaworks3D and its Airplay SDK for the N-Gage edition. Designer James Blackham describes blocking out levels and guard routes in Maya, writing codec dialogue and using Lua triggers and timers for gameplay. Those accounts document work on the N-Gage project. A separate Java engineering credit roll for SoftBank has yet to surface in this pass.[5][6]

Release and reception

The first Japanese release was on KDDI’s EZweb on January 31, 2008. Verizon was selling the game in the US by March 20, Japan’s i-mode release followed on June 2, and Nokia listed the N-Gage edition in December. On February 6, 2009, Konami released the Java S! Appli edition through Yahoo! Keitai on SoftBank for ¥525.[7][8][9][10][1][4]

Edition notes

The archive records two files labelled as Japanese J2ME releases. The carrier coverage establishes the Sharp 932SH edition and the trial. It does not match either label to a specific official download or to the preinstalled trial.[11][3][1]
