FIELD NOTES

Keep the game.
Keep its story.

A catalog for the games Wakka brought back—and the much larger set of trails still worth following.

Why this one exists.

The BREW, Zeebo, ExEn, and DoJa catalogs follow different corners of the same pocket gaming rabbit hole. This J2ME catalog starts with the ten games documented in Omni Player’s public guide, then reaches into larger bibliographic collections.

The first public catalog joins 989 explicitly labeled J2ME directory listings with two additional Omni recovery titles. That gives each entry a stable page without pretending the wider research collections have already been reconciled into one definitive game list.

One title can have many editions.

Source labels show different screen sizes, handset families, versions, and languages. A filename can be renamed by a collector; a JAR can be paired with a JAD descriptor. Two matching titles do not establish matching files.

The recovery pages preserve the recorded bridge input separately. A Sony Ericsson K790 listing for Nowhere, for example, is a useful candidate for the K790 input in the guide. It still needs a comparison with that original input to establish identity.

Three different kinds of evidence.

  • Omni recovery record: title and input edition recorded by Wakka in the public game guide. This is a report of that guide, not a new compatibility test.
  • Source-listed metadata: a title, date, credit, or edition label transcribed from an attributed source. The source can be mistaken or incomplete.
  • Title-level candidate: a connection made by a reviewed alias or normalized title. It helps discovery without establishing the same platform or build.

What stays unresolved.

Resident Evil: Uprising has conflicting creator labels between the guide and external records. The Witcher: Crimson Trail has a language distinction that a matching Nokia N73 label does not resolve. Those differences remain visible on their pages.

Digital Devil Story: Megami Tensei is labeled J2ME in the starting sources. A broad Java platform label is not enough to settle every runtime-family distinction, including DoJa versus standard MIDP. The original runtime metadata has not been inspected here.

How matches were made.

The main directory titles are compared with the bibliographic sources after Unicode normalization, case folding, punctuation removal, and converting “&” to “and.” Explicit aliases are also used for the ten recovery titles. Every such link remains a title-level candidate. No fuzzy title score is used to silently combine records.

The file inventory is separate: it preserves source-listed filenames, sizes, and reported hashes without assigning those files to canonical games by guesswork. The J2ME Vault mirror attributes its material to Kahvibreak, so a matching record in both is not independent corroboration.

How to read the numbers.

A catalog entry, a source row, an edition-label group, and a file are different units. Source collections overlap. Their totals are never added together as a count of distinct games. Release years come from a platform-scoped fact table or the explicit J2ME directory; RG’s date-added field remains a date added to that source.
